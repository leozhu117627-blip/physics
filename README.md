# 高中物理教案庫

用 Claude 的「物理教案產生器」跑出教案後，到 `upload.html` 一次把檔案丟上來，
首頁儀表板會自動更新課綱覆蓋地圖、議題融入統計與資源庫存。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 首頁儀表板（公開瀏覽） |
| `upload.html` | 新增／刪除教案的管理頁（需 GitHub Token 才能操作） |
| `lessons.json` | 教案索引，由 `upload.html` 自動維護，通常不需手動編輯 |
| `assets/curriculum.js` | 108 課綱章節、19 項議題、資源類型定義 |
| `lessons/` | 各教案的實際檔案，由上傳頁自動建立子資料夾 |

## 注意

倉庫是公開的，任何人都能看到檔案內容，請勿放入學生個資。
上傳用的 Token 只存在管理者自己的瀏覽器，不會出現在網站上。
