1連線設定

只需設定一次，之後這台電腦會記住。

第一次使用？點這裡看怎麼拿到 Token（約 3 分鐘）
  1. 登入 GitHub，打開 Fine-grained personal access token 建立頁
  2. Token name 隨便填，例如 物理教案上傳
  3. Expiration 建議選 No expiration 或 1 年
  4. Repository access 選 Only select repositories → 勾選你的教案倉庫
  5. Permissions → Repository permissions 找到 Contents，改成 Read and write
  6. 按 Generate token，把出現的那串字複製貼到上面欄位（只會顯示一次）

金鑰只存在你自己的瀏覽器，不會上傳到網站上；別人打開這個頁面看不到，也不能上傳。
